Para executar a aplicação, é necessário ter o Python 3.10 ou superior e o pip instalados. 
Dentro da pasta aula3, execute pip install -r requirements.txt para instalar as dependências. 
Em seguida, inicie a aplicação com uvicorn app:app --reload. 
A API estará disponível em http://127.0.0.1:8000/docs. 
O banco de dados SQLite será criado automaticamente na primeira execução.
